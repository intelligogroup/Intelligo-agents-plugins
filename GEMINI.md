# Intelligo Clarity

This extension connects Gemini to **Intelligo Clarity**, a risk-intelligence platform
for background checks, credit checks, and social-media screening.

Tools are provided by the `intelligo-clarity` MCP server
(`https://clarityapi.intelligo.ai/mcp`). Authentication is handled by the server via
OAuth on first connect — there are no API keys to configure.

Use Clarity's tools to:

- Summarize a profile's background, credit, and social findings, with red/yellow flags.
- Compare reports — what changed since a prior report, or what overlaps across profiles.
- Surface risk trends across many reports (flags over time, emerging risks, keyword search).
- Prepare investment-committee materials from Clarity findings.

A valid Intelligo Clarity account with Clarity API access is required.
