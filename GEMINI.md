# Intelligo

This extension connects Gemini to **Intelligo**, a risk-intelligence platform for
background checks, credit checks, and adverse-media and social-media screening.

Tools are provided by the Intelligo MCP server (`https://clarityapi.intelligo.ai/mcp`).
Authentication is handled by the server via OAuth on first connect — there are no API
keys to configure.

Use Intelligo's tools to read your projects, profiles, and report content — summarize a
subject's findings and risk flags, compare reports, and surface risk across your
portfolio.

A valid Intelligo account with API access is required.
